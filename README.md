# Repository Guide – Two Instance Families (EC and RP)

This repository archives **input data instances** for two distinct experimental settings used in the companion study:

1. **EC (Error Components)** instance family  
2. **RP (Random Parameters)** instance family

Because the two families follow different modeling assumptions, parameter-generation logic, and filename metadata, the documentation is split into **two dedicated README files**, one per family.
